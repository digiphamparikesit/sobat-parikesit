💊 Data Pasien Sobat

📤 Upload CSV Dok

Format CSV (baris pertama = header):

nama,alamat,no_hp,tarif(rupiah),pendapatan_rs,pendapatan_petugas,petugas,bulan,tahun
A MUSNI,KEL LOA IPUH...,08123456789,150000,90000,60000,SUGENG,Januari,2025
BUDI SANTOSO,JL MERDEKA...,08129876543,200000,120000,80000,SANDI,2,2025
  • tarif — total biaya. Boleh 150000 atau Rp 150.000
  • pendapatan_rs — bagian RS (opsional, default 0)
  • pendapatan_petugas — bagian petugas (opsional, default 0)
  • petugas — nama petugas (SUGENG/SANDI/VIONA)
  • bulan — angka 1-12 atau nama (Januari, Feb, dst)
  • tahun — 4 digit (contoh 2025)
  • Baris duplikat (nama+no_hp+bulan+tahun) otomatis dilewati

📋 Paste Data dari Excel

Cara pakai:
  1. Buka Excel / Google Sheets, blok data termasuk baris header
  2. Ctrl+C (copy)
  3. Klik kotak di bawah, tekan Ctrl+V (paste)
  4. Klik 👁️ Preview → cek data → 💾 Simpan ke Antrian

Kolom yang dibutuhkan: nama, alamat, no_hp, petugas (opsional). Urutan kolom bebas, asal ada header.
